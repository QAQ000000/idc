# JianYun (简云) · 研发路线图与交付里程碑 (Milestones)

本文档规划了 JianYun 项目的工程实施路径。每个 Milestone 必须跑通端到端测试并形成可演示成果，严禁脱离实际运行盲目推进。

**2026-11-07 技术栈定案**：PHP 8.4 + Laravel 13 + MySQL + Redis + 单一 Vue 3/Element Plus 前端，详见 [TECH_STACK.md](TECH_STACK.md)。M0 已完成现有 MVP 的 Laravel/PHP 8.4 适配；M2 新购、选配与续费已有下文所列真实样本证据，商品与异常运营入口已补齐，当前补齐实例日常运维。后续优先级见本批记录，已完成样本不代表全部驱动、全生命周期或生产割接验收。

## 阶段三：事务发件箱、双阶段自动续费与快照调度 (Reliable Engine)
> **目标**：彻底消灭“漏单、吞单”和“有钱不续费停机”两大历史 Bug，落地自主快照备份计划任务。
