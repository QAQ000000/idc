# M2 客户实例重装契约

## 范围与协议证据

同一 Vue 实例详情页提供可选重装能力；只有驱动明确声明、原账号资源归属与账期一致、服务有效且无任务／资金占用时才允许提交。首批仅支持魔方 `dcimcloud`、`module_button.control` 明确声明 default/reinstall、上游 `/host/header` 返回有效 `cloud_os` 的实例。其他模块、裸金属、手工资源均不推断支持。

协议依据是旧财务 `Host::reinstall`、`DcimCloud::reinstall` 与已留存商品 14 的 header：`/provision/default` 接受 id/func=reinstall/os/is_api=1/format_data_disk=0；云模块不接受客户自定义密码，而是上游生成。首批密码模式明确显示为上游生成，不收集或忽略自定义密码，不额外发起重置密码。镜像 ID 为财务返回的选项 ID，不能替换为底层 OS ID。数据盘固定“不请求格式化”，不开放全盘清空；此参数不是数据无损承诺，客户须备份。

## 提交与可靠执行

GET `/api/v1/instances/{id}/reinstall` 只读能力、镜像与最近 10 条任务；签发 120 秒确认令牌，绑定客户、实例、资源／状态版本和能力摘要。POST 同路径要求镜像、原令牌、request_key 和 `confirmed_system_disk_erase=true`。页面先选择镜像并勾选备份／系统盘清空，再弹窗二次确认。禁止代登录提交。

HTTP 网络读取在事务外；提交锁实例，重新检查版本、归属、客户／上游启用、所有排队任务和 TaskGate，再写 invoice_id=NULL、action=reinstall、max_retries=0。payload 冻结原绑定、镜像、能力摘要与请求客户；不含明文密码。不创建账单，不改资金、账期、续费价、原商品快照或资源绑定。

Worker 发送前重新读取上游能力并比对摘要。只允许首次 running 发送一次，租约接管一律 investigating，只读、不重发。响应 200 仅表示受理，不能依据 Active、镜像字段改变、开机状态或上次进度 100% 推定重装完成。当前魔方云接口没有可关联本次操作的完成回执，因此受理后只读调查并转持久人工核验；页面显示已受理／结果未知／待核验，不伪造百分比。

## 凭据与人工回填

重装 pending/running/investigating 或 failed+MANUAL_AUDIT_REQUIRED 期间，原密码查看入口拒绝返回旧密码。管理员原任务入口只允许 investigate / fulfill / close_unexecuted，不开放重试、退款或新购取消。fulfill 要求原资源、旧执行令牌、实际完成证据、明确完成确认和已核实的新用户名／密码；新密码 AES-256-GCM 加密，仅更新 delivery 与 encrypted_password，同事务审计不存密码。普通支持人员不能读取或回填密码。close_unexecuted 须证实原请求未执行且没有延迟请求，解除占用但不改凭据。终态与旧 Worker 由执行令牌隔离。

未来具备可关联完成回执的驱动可返回 succeeded 与核实的新凭据，复用同一原子回填；不能用协议夹具声称真实魔方支持该回执。
