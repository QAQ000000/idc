# 管理员实例续费改价

## 范围与价格

沿用 `/admin/instances/:id`，展示实例原冻结 `recurring_price`、可空覆盖 `override_price`、当前有效价及账期。恢复原价是清除覆盖，不能读取当前商品目录价格重定价。金额沿用已有付款能力，只接受 0.01–99999999.99 的十进制字符串，不新增免费续费模式。

财务／超级管理员可查看价格与最近20条改价审计；客服／运维不返回价格。只有当前启用的超级管理员可设置覆盖价或恢复原价，必须提交版本和10–1000字节修改依据；不读写上游，不处理当期补差、变配或退款。

## 原子变更与竞争

`GET /api/v1/admin/instances/{id}/renewal-price` 返回价格、版本、是否可编辑、门禁说明、将受影响的未付续费单和近期审计。`PATCH` 同路径只接受 `{override_price: "12.00" | null, expected_version: "…", evidence: "…"}`。版本绑定实例归属、资源、状态、账期、到期日、冻结价、覆盖价及最新改价审计ID，拒绝旧版本与改价后恢复原值的ABA提交。相同覆盖值（含均为null）提交拒绝，不作废账单。

短事务先锁原实例，检查已交付active/suspended、已知资源／到期日及现有月／年账期，再执行统一任务／资金门禁并拒绝所有其他pending任务；包括未完成的新购、续费、销毁与运维，租约过期不放行。锁后校验版本与当前超级管理员身份；改价、原实例所有归属一致的unpaid renew账单CAS cancelled、cycle_marker=NULL及完整审计同事务提交。任何一步失败整体回滚。已付／取消账单和收款尝试不改写；后续由原出账服务按当前有效价出账，本请求不调用上游预检或直接代扣。

付款、回调、代扣和改价共用实例行锁：改价先提交时，旧单不能再正常付款／代扣；原渠道的真实迟到款经原凭证唯一键和账本幂等键全额入钱包，不顺延账期、不派renew、不累计消费或佣金。付款先提交时，旧价已购权益保持，原版本因账期变化失效，且未决renew门禁阻止改价；履约确认后可刷新版本调整后续价格。新旧收银台同时实收时，各凭证独立记账，仅当前有效新单能够购买一次账期。

## 页面与验收

现有详情新增价格卡和标准Element Plus弹窗；选择覆盖／恢复、显示前后价格与受影响账单、输入依据后确认。提交中禁重复／关闭；409清除旧编辑并刷新重看，网络结果未知时先刷新价格和审计，禁止自动重试。加载／无覆盖／无未付单／门禁／失败状态明确，手机和竖屏平板复用单列及现有弹窗样式。原只读实例／账单入口不改变其权限。

需隔离验证权限、金额、旧版本／ABA、各任务／资金门禁、审计失败全回滚、价格／作废／周期标记一致性，改价与手动付款／自动代扣／验签回调竞争，以及旧收银台取消后迟到／重复／额外实收。已付历史、原资源／配置／已购账期和冻结价须保持。测试不连接M2或正式业务库、不产生真实上游操作；真实运行证据与隔离检查分开记录。

27表和DDL保持，无迁移、通知渠道、价格实体或同步工具。核心只依赖原领域服务与插件契约，驱动无需为改售价扩展。
