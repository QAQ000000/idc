# 客户账号运营最小闭环

状态：开发及隔离验收完成；M2 运行接入及真实客户验收未执行。

## 冻结边界与变更原因

原客户详情只读，无法处理客服停用和账号密码重置。本批在原详情顶部增加超级管理员账号操作弹窗，保留其他启用管理员的只读查询和原财务权限。复用 users.status（active/suspended）、auth_version 与不可改 admin_audit_logs，不增加表、列或迁移。

- 停用拒绝后续登录、客户主动操作及新余额代扣；启用、停用、管理员重置密码均递增 auth_version，使旧 Token 和旧找回链接永久失效。启用不改 auto_renew，重新符合门禁的原单可由后续扫描代扣，页面须明确告知。
- 不触发资源停机／销毁，不取消已付账单或任务，不删除余额、收款或实例。不阻断旧支付回调正常结算及迟到／额外款入钱包。已签发的云控制台直连凭据不能由本站即时撤销，沿用原短效及前端连续校验边界。
- 操作以账号行锁为提交边界：先取得锁并获准的操作可先完成；停用提交后等待锁的主动写操作重新检查状态及当前请求认证版本。新余额代扣与停用共享原钱包行锁；旧已付款分支不再次扣款。
- 后台变更先锁当前管理员并复核启用状态、超级管理员角色及登录认证版本，再锁客户；只写客户账号与审计，不反向锁实例／账单／任务。
- 版本为客户 id/email/status/auth_version 的 HMAC，不包含余额或 updated_at；支付入账不使账号编辑无谓失效，客户改密及状态 A→B→A 均使旧预览失效。
- 重置密码为显式输入 12–72 字节、不含 NUL 的密码，哈希写库；不回显、不进审计，不自动发信或代登录。操作依据不得填写密码。

## API 与页面契约

仅当前启用 super_admin：GET `/api/v1/admin/customers/{id}/account` 返回安全账号投影、版本和最近 20 条账号审计。PATCH `…/{id}/status` 与 POST `…/{id}/password` 均要求 expected_version、evidence（10–1000 字节）、request_key（UUID v4）和 confirmed=true；分别附 status 或 new_password。未知字段拒绝；空变更及过期版本 409；变更、auth_version 递增和脱敏审计同事务。

request_key 仅作审计关联，不是登录凭证；不另建请求表。原版本重复提交只能成功一次。响应未知时 GET 可按原 request_key 查询本次审计（不受最近 20 条截断影响），不自动重发；同版本且没有本次审计仍保持未知，不能因“已配置密码”或当前状态相同推定本次已成功。已发生其他变更时先展示冲突，显式采用新版本后才可创建新操作。

页面保留客户资料、关联定位和实例分页；账号操作和近期审计按需打开弹窗，不增加长面板。弹窗内明确续费影响、确认客户身份及操作依据。密码仅留当前编辑区内存，失焦／后台／关闭／离页／提交后清除；未保存或未决离页提醒。分页和刷新不盲目重提操作。

- 注入真实审计写入故障时，启停、密码和认证版本整体回滚；两个管理员同版修改、两个同版密码重置各只成功一次。角色／登录版本等待期间被撤销的管理员拒绝写入。

- 停用后普通旧充值、取消后迟到充值及旧新购收银回调仍成功，重复不增加流水／任务，旧已付新购任务及续费任务继续履约。停用不改变原资源状态／绑定／账期／auto_renew，账号连续操作不修改账单／凭证／流水／实例／任务事实。
- 原审计超出最近20条后仍能按操作编号精确定位，不建设请求副本。独立PHP-FPM在配置缓存前后各通过角色／安全投影／启停／永久会话撤销／重复重置检查，无跨请求身份串用。

## 复杂度变化

新增一个小型账号领域服务、三个HTTP入口及原详情的独立弹窗；最终主动操作认证复核抽为一处，替换现有重复状态检查。原auth_version和审计承担版本、防重和丢响应核对，不增加会话表、请求实体、客户数据副本、后台任务、通知场景或资源调度。客户页只对当前客户的query分页稳定挂载，离开客户身份仍确认并清除明文，不强制其他页面采用公共骨架。
