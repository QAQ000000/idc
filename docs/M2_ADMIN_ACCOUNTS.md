# 管理员账号管理最小闭环

## 身份与范围

同一Vue后台增加 `/admin/accounts` 和 `/admin/accounts/:id`，仅当前启用super_admin读取账号、创建、启停、分配现有super_admin／finance／support／operator角色及显式重置他人密码。用户名／邮箱创建后本批不编辑，不增加自定义权限、删除账号、公开管理员注册、代登录或二次认证配置。账号详情展示角色、状态、最近登录及安全变更审计，密码／密码哈希／二次认证密文均不返回。

所有启用管理员在 `/admin/account/security` 验证旧密码后修改本人密码；超级管理员不能通过“重置他人”绕过本人旧密码验证。新密码12–72字节、拒绝NUL，服务端Bcrypt；提交后清空表单，不回显、不写入审计／日志。原二次认证要求保留，当前无法通过二次认证登录的账号不计为“可登录超管”，不通过重置密码解除二次认证。

## 会话与版本

原admin_audit_logs只追加且已有idx_target，账号最近的admin_account_create／admin_account_update／admin_password_change／admin_password_reset审计ID作为认证版本。现有CLI的admin_provision不改旧版本0，旧缺av Token只兼容尚无安全变更审计的版本0；新登录带av。中间件重查账号及最新版本，改密／重置／停用／调岗后旧Token失效；重新启用会再次留审计，旧Token不能恢复。客户会话独立，不受影响。

这直接复用必须保存的安全事实，代价是每次管理员鉴权多一次按目标账号索引查询；相较新增撤销表／缓存同步／认证版本列，省去新事实来源和迁移。审计不得清理、改写或绕过领域服务写管理员字段，否则破坏撤销保证。无新表、列、DDL或迁移，仍27表。

目标版本为ID／固定资料／状态／角色／二次认证配置标识／最新安全审计ID的HMAC，不含密码。修改、重置和本人改密都须提交版本；角色A→B→A及同一秒多次操作不会复活旧预览。写事务重核请求时认证版本和当前角色，等锁期间会话已撤销也不能继续写。

## 事务与最后一名超管

账号管理写操作按ID顺序锁定原admins行集；管理员数量小、写入低频，以短事务串行化账号变化，避免引入锁表／Redis锁或复杂锁协议。密码校验和Bcrypt计算在事务外，事务内只比对原凭据指纹、版本、当前身份、唯一键与最后超管条件，再写变更及不可改审计。CLI创建复用领域验证与审计，不提供CLI停用／调岗捷径。

变更后必须至少保留一名active、super_admin、有受支持密码哈希且未被当前不支持的二次认证阻挡的账号。并发互相降权／停用必须在原行锁内重数；不能把已停用或无法登录的超管当兜底。本人停用／降权仅在另有可登录超管时允许，成功后本站退出当前管理员会话。已合法受理的业务任务／邮件不因管理员变更被取消，资金／资源／Outbox不在本批修改范围。

账号变更与审计同事务，审计失败回滚；唯一用户名／邮箱防重复创建，不将密码或其派生摘要写入审计。响应未知先重读账号／审计，创建按原用户名定位，重置／修改重新确认新版本，不盲目重复提交。无变化拒绝，不制造撤销或审计。

## 页面与验收

Element Plus标准列表、详情和弹窗，分页／用户名或邮箱搜索／状态与角色筛选进入URL；加载、空结果、读取失败、409重新加载、密码不回显和手机／竖屏平板同步验证。列表与导航不能替代后端权限。

验收覆盖创建→登录→调岗／停用→旧会话拒绝→重新启用旧会话仍拒绝；本人旧密码错误／正确、显式重置、角色与客户身份隔离、版本／审计回滚／最后超管并发竞争。冻结认证契约的变化是引入管理员会话撤销，影响原AdminAuthService、中间件、账号领域服务、后台导航与API／字典／路线图摘要；无迁移、不重置历史账号或真实密码。隔离与页面证据见下节。
