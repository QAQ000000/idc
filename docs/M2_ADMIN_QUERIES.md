# 管理员客户与实例只读查询

## 范围与数据边界

本批复用单 Vue／Element Plus 后台和原 MySQL 事实，增加客户、实例查询及关联导航。所有当前启用管理员可查询账号状态、客户邮箱、实例归属、商品、服务状态及账期；不提供编辑、改密、代登录、上游刷新、电源、VNC、改账或退款动作。查询只读本地，不调用驱动，不增加表、索引、迁移、缓存副本或后台任务。实例状态是本地服务／交付状态，不声称是实时电源或上游可用性。

所有新接口使用 admin 中间件，服务重查当前启用身份。字段显式投影，不返回密码／密文／Token、配置快照、上游 endpoint、原始错误、任务载荷、任意审计 JSON 或钱包余额。客户 Token／匿名 401、停用管理员 403、参数错误 400、详情不存在 404；响应 no-store。资金只能经原 FinanceQueryService 的 finance／super_admin 权限读取，前端隐藏仅作展示，不能替代后端授权。

## API 与页面

API 前缀 `/api/v1`，列表均为 items/total/page/per_page，page 默认 1、最大 100000，per_page 默认 20、最大 100，ID 倒序；超界页空结果。

| 接口／同名页面 | 行为 |
|---|---|
| GET /admin/customers | user_id、精确 email（最长 100）可组合筛选；返回 id/email/status/created_at，无财务汇总 |
| GET /admin/customers/:id | customer 与分页 instances（page/per_page）；关联列表固定该客户，不能用 query.user_id 切换归属 |
| GET /admin/instances | instance_id、user_id、provider_id（上游接入批次新增）、name（最长 100，字面子串）、ip_address（最长 45，精确）、remote_instance_id（最长 100，精确）组合筛选；返回实例、客户、商品及上游编号，不返回上游账号信息 |
| GET /admin/instances/:id | instance 与本实例／客户一致的分页 invoices（page/per_page）；账单仅编号／类型／状态／时间，金额与渠道继续去原财务详情查看 |

客户详情链接该客户实例、异常任务及（财务权限）账单／收款／钱包列表。实例详情列原账单编号和类型／状态，链接对应任务以及（财务权限）原账单资金详情；另外提供该实例全部账单、收款和相关钱包流水的筛选入口。沿用原详情，不复制一套资金／任务页面。任务列表新增 user_id 筛选，资金列表新增 instance_id 筛选，均使用参数化查询并核验账单归属。

关联导航也暴露了既有任务投影的权限缺口：之前客服／运维可读 total、续费价、收款明细和审计结构化金额。本批将这些财务字段置空、收款列表置空并移除结构化金额／凭证字段；原账单编号／状态／付款时间和业务门禁保留，财务／超级管理员继续可读。任务裁决逻辑、证据、令牌与事务完全沿用原服务。历史审计 evidence 属于原人工材料，运维录入不得包含凭据；本批不自动解析或改写自由文本。

## 页面状态与验收

四页沿用公共外壳、标准表格／descriptions、中文标签和 UTC 时间。筛选／页码进入 URL，提交搜索回第一页，清空后恢复全部；刷新、返回和直接打开链接保持筛选。加载遮罩／骨架、独立空结果、错误重试及 404 提示；出错不把旧结果当作本次结果。详情分页禁并发，表格内部横向滚动，长邮箱／IPv6／资源编号可换行，手机单列、不造成整页横向溢出。管理员登录站内 redirect 白名单新增四页，客户登录态仍独立。刷新／快速导航时鉴权网络失败或 503 不再删除有效令牌，但清空未验证角色并回到管理员登录；恢复后重新核验当前身份才允许进入。401／403 仍清除会话；不沿用旧角色放行。此为关联导航中发现的会话误退出修正，无令牌格式、接口或迁移变化。

验收：邮箱→客户→实例→账单→收款／流水→异常任务；分别覆盖匿名／客户／四种管理员角色、停用与现有令牌降权、分页、恶意／数组参数、LIKE 字面转义、缺失与空结果、跨客户过滤及敏感字段不返回。所有写请求拒绝，不修改资金、账期或任务。浏览器只使用独立夹具，桌面及 390／320px 手机宽度验证；真实 M2 最多做已有身份的只读查询，不付款、不操作上游。

## 后台实例样板的展示兼容（2026-11-09）

本页后来接入续费价和人工补差后，不能再因详情刷新或账单翻页重建组件而丢失未决结算。本批仅 `/admin/instances/:id` 改为页内四分区／账单分页，进入时仍读取原 URL 的 page／per_page；页内切分区和翻页不改 URL，F5 回到入口页码，不承诺分享当前分区／页码。实例／客户列表及客户详情原 URL 筛选与分页保持。
