# 客户实例详情页：分区、任务与凭据保护

## 范围和生命周期

本批仅 `/instances/:id`，按“概览、系统维护、账期与续费”分区。默认概览保留 VNC 与电源入口；规格、已有历史按需展开。复用当前 Vue／Element Plus、原任务／能力／确认API及Outbox，不提炼公共骨架、不改后台样板或通知配置。

页壳按实例ID稳定挂载；分区用本地状态，不改URL。电源／重装面板非懒加载，切分区不重新挂载或触发查询；各面板仍各自持有唯一串行15秒定时器，非必要远端运行观察仍限2分钟。详情重读不能卸载面板；读取失败标注上次资料并暂禁操作，保留未决跟踪，首次失败为空错误重试。离开实例路由仍卸载并清理定时器。

| 分区 | 内容 |
|---|---|
| 概览 | VNC、电源状态与命令、折叠规格；常驻摘要显示本地交付／权益、上游核验与未决操作提示。正常状态验收首屏入口，异常原因不为凑坐标而隐藏。 |
| 系统维护 | 按需展开登录凭据、原重装镜像／备份确认与历史、原上游服务核对。仅驱动明确支持才可操作，不增加自定义密码或变配入口。 |
| 账期与续费 | 原冻结约定续费价、周期／到期日、原续费账单与余额自动续费。沿用原账期与门禁，不自动补差／退款。 |

## 操作意图与跟踪

确认／提交与结果未知的操作上下文留在原面板内存；分区切换、详情重读不生成新UUID或POST。结果未知只读调查，不能重新确认后另投一次重启／重装。未决及读取失败摘要常驻页壳；错误不抹掉原任务记录，过期租约不解除占用。

可信业务拒绝后才解除当前提交意图，重新查询能力与令牌并要求确认；网络错误、网关非业务响应或无法确认的返回按未知处理。本地只读列表观察到提交后的新任务，会使原确认版本失效，之后按该任务记录与门禁继续跟踪；不能用当前on/off证明未知命令完成。持续读不到新任务时保留未知、继续查询并提示管理员，不按超时自动解锁。旧确认不重发。

重装在途轮询只读 `?view=tasks`；观察到终态后完整重取镜像／能力／令牌，并清除备份确认，再次提交须重新确认。电源原runtime查询重新取得能力与令牌；重装与电源的占用变化相互触发必要的能力重读，不因切回分区增加定时器。无需新增任务实体、后端接口或恢复队列；F5不承诺恢复浏览器未落盘意图，后台任务与服务端版本仍裁决。

## 明文凭据

凭据仅在“系统维护”的凭据查看区域显式读取，不进入持久存储、摘要或操作日志。隐藏／折叠、切分区、区域离开视口、页面进入后台、pagehide、路由离开和重装开始均立即清空明文并递增请求版本；迟到成功／错误不得重新显示凭据或污染新区域。读取中也可取消；取消后旧请求不持有新的读取锁。页面恢复可见／切回时不自动再取凭据。

任务开始或重装记录变化清空旧凭据；在途、未知或读取失败期间不能使用陈旧能力打开旧凭据。任务结束只重新开放按需查看，不自动展示新密码；执行已结束不当作系统成功或可登录证据。

## 兼容与成本

前端保留原API与业务门禁，API客户端仅区分已解析的业务错误与网关／解析错误，避免把后者当作已回滚；不改变请求、认证或服务端错误协议。保持27表，无迁移、Worker或驱动变更，不触发真实M2清盘／电源／付款。增加页内分区、操作摘要／未决意图和凭据可见区域管理；去掉刷新造成的重挂载与重复确认风险，不新增通用页壳或持久恢复副本。

- 任务跟踪：隐藏分区的power与reinstall均保留唯一串行查询；反复切区没有新增查询或POST。除浏览器时钟推进检查外，还实际等待15.5秒，确认各自恰好一次查询，重装只读 `?view=tasks`、没有完整能力重读。查询失败保留原任务与页壳阻断，后续继续查询；详情重读失败不卸载面板。
- 凭据：显式读／隐藏、折叠、切区、区域滚出视口、模拟后台／pagehide、详情重读、路由进入后台或实例列表、重装确认均清除明文；取消旧读取后可立即新读，迟到成功不回显、迟到错误不覆盖新结果。返回区域不自动读取，sessionStorage／localStorage不含测试密码。凭据故障由合成响应模拟，不用真实主机密码作截图证据。
- 操作意图：提交中切区、网络丢响应、无任务记录、非业务409及HTTP409却携带成功码的矛盾返回均不允许另起请求；可信业务拒绝才解除本次未知，重新获取能力与令牌。终态重取后，再次操作确实使用新令牌、新请求键和显式确认，重装备份勾选被清除；不将on/off当作未知命令已执行。
- 真实隔离服务链：在本地协议夹具资源 `host:788` 上，电源任务#196与重装任务#197分别由原API真实落库，再人为丢弃浏览器响应；页面读回原任务，均只提交一次。原Worker将电源结案；重装获得结构化执行观察后，夹具转idle，Worker自动同步新凭据、标记 `execution_ended`、解除占用。原资源、2026-12-09账期、月付与¥0.01续费价保持不变。此证据仅证明本地协议／自动跟踪集成，不证明现网供应商提供字段或系统可登录。
- 类型检查、ESLint零警告、Vite生产构建、27表字典同步及Git差异检查通过；构建保留原Element Plus公共包超过500kB提示。没有新增依赖或后端／插件引用，不突破物理隔离。
