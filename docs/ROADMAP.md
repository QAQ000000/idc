# JianYun (简云) · 研发路线图与交付里程碑 (Milestones)

本文档规划了 JianYun 项目的工程实施路径。每个 Milestone 必须跑通端到端测试并形成可演示成果，严禁脱离实际运行盲目推进。

---

## 路线图总览

```text
Milestone 1: 极简内核与单链路闭环 (MVP)
     ↓
Milestone 2: 驱动插件体系与魔方代理对接 (Provider Driver)
     ↓
Milestone 3: 事务发件箱与双阶段自动续费 (Reliable Engine)
     ↓
Milestone 4: 实例运维控制台与改价补差 (Ops & Billing)
     ↓
Milestone 5: 返佣防套利与生产数据平滑导入 (Affiliate & Migration)
```

---

## 阶段一：极简内核与单链路闭环 (MVP)
> **目标**：用户注册登录、浏览一个模拟商品、生成账单、模拟付款成功、落库待交付任务。

- [ ] **任务 1.1**：初始化后端基础框架（REST API 结构、统一返回格式、数据库连接池与迁移运行器）。
- [ ] **任务 1.2**：实现 `users` 表鉴权（JWT / Bearer Token 机制），包含密码哈希、登录、注册。
- [ ] **任务 1.3**：实现基础 `invoices` 与 `transactions` 资金扣减事务服务。
- [ ] **任务 1.4**：实现 `tasks` 事务发件箱基础模型（同事务写入）。
- [ ] **验收标准**：通过 API 自动化测试，模拟完成一次“注册 $\rightarrow$ 充值余额 $\rightarrow$ 购买 $\rightarrow$ 扣款 $\rightarrow$ 任务入库”的完整事务链路。

---

## 阶段二：驱动插件体系与魔方代理对接 (Provider Driver)
> **目标**：打通与真实上游魔方（SakuraIDC / 创峰等）的 API 代理，实现配置透传与自动开通。

- [ ] **任务 2.1**：定义统一 `UpstreamDriverInterface` 抽象规范。
- [ ] **任务 2.2**：实现 `ZjmfProxyDriver`（对接智简魔方开放 API）：
  - `getFormSchema`：拉取魔方配置项并缓存为 JSON 快照。
  - `preflightPrice`：下单前向魔方预检校验价格与库存。
  - `create`：向魔方提交新购开通。
- [ ] **任务 2.3**：实现自营插件驱动：
  - `Sub2ApiDriver`：AI 额度兑换码分发交付。
  - `ManualAdminDriver`：人工运维待开通工单流。
- [ ] **任务 2.4**：前端选购组件 `<ConfigOptionRenderer />` 动态解析 JSON 渲染滑块/单选。
- [ ] **验收标准**：在测试环境下，前端选择配置下单，能真实调用上游魔方接口成功开通一台 VPS，实例表记录到正确的 IP 和远端 ID。

---

## 阶段三：事务发件箱与双阶段自动续费 (Reliable Engine)
> **目标**：彻底消灭“漏单、吞单”和“有钱不续费停机”两大历史 Bug。

- [ ] **任务 3.1**：实现后台守护 Worker（基于 Redis 队列或轻量定时扫描）：
  - 提取 `tasks` 中 `pending` 状态任务。
  - 调度对应 Driver 执行，遇到超时自动记录日志并安排指数退避重试（5m, 15m, 30m）。
  - 达到最大重试次数自动报警，后台提供【一键重试】按钮。
- [ ] **任务 3.2**：实现双阶段自动续费守护器：
  - 出账器：提前 7 天扫描生成唯一续费账单（`uk_cycle_instance` 防重）。
  - 代扣器：每 15 分钟扫描未付账单，余额充足即行锁扣款，并生成 `renew` 任务。
- [ ] **验收标准**：模拟上游网络中断 3 次，恢复后 Worker 能自动重试成功并履约；模拟用户提前充值与临期充值，均能准确秒级代扣并续费。

## 阶段四：实例运维控制台与改价补差 (Ops & Billing)
> **目标**：完善客户日常高频操作，提供后台运维改价补差神器。

- [ ] **任务 4.1**：客户控制台实例管理功能：
  - 电源操作：开机、关机、重启。
  - 重装系统：拉取镜像列表并执行重装。
  - 在线 Web VNC：免密透传远程控制台。
- [ ] **任务 4.2**：弹性云动态升降级引擎：
  - 升级按剩余天数折算差价，付完款调上游变配。
  - 降级按“0 元不退款”执行，自动下调下次续费价。
- [ ] **任务 4.3**：后台管理员改价弹窗：
  - 支持手动输入新的续费价格（更新 `override_price`）。
  - 自动折算当期差价，一键从用户余额扣除并生成 Paid 账单。
- [ ] **任务 4.4**：后台“以该客户身份登录（Login as Client）”运维功能。
- [ ] **验收标准**：全流程测试变配补差计算精度无误；后台手工改价后下期账单准确按新价格出账。

---

## 阶段五：推广返利防套利与旧数据平滑导入 (Migration)
> **目标**：防羊毛党闭环，平滑导入正式站 3,363 个客户与 118 台存活实例。

- [ ] **任务 5.1**：实现推广返利冻结与结算状态机（15 天冻结期）。
- [ ] **任务 5.2**：实现退款级联冲正逻辑：
  - 冻结期内退款：立即作废佣金。
  - 已结算退款：触发 Clawback 扣减余额。
- [ ] **任务 5.3**：编写旧数据库（`idc2`）平滑迁移脚本：
  - 导入存量 3,363 位用户的密码哈希与可用余额。
  - 导入当前正在运行的 118 台 Active 实例（映射到对应 Provider）。
- [ ] **验收标准**：完成数据迁移并在新系统中成功登录旧账号、查看到旧实例并可正常执行重启与续费。
