# 最小客服工单闭环

## 交付范围与页面

同一Vue应用增加客户 `/tickets`、`/tickets/new`、`/tickets/:id` 和管理员 `/admin/tickets`、`/admin/tickets/:id`。列表分页、状态筛选，后台可按工单ID／客户ID或邮箱／实例ID定位；详情展示纯文本会话、状态、客户可见的本人关联实例。管理员链接现有客户与实例详情，资金仍按原财务权限查询。使用Element Plus标准表格、表单和单列会话，长文本换行；加载、空状态、错误重试、关闭／权限冲突和手机体验同步验收。

客户新建填写主题、正文及可选本人实例（本地分页搜索，不查询上游）；首条正文和工单同事务提交。详情追加回复或确认关闭；关闭前若出现新消息，旧版本409，刷新核对。后台所有当前启用管理员可查询、公开回复和结单；不提供内部便签、转派、附件、富文本、代登录或自动邮件。工单只沟通，不执行退款、改价、重装、任务裁决或资金操作。

## 状态、归属与重复请求

状态复用原枚举：新单open，客户追加customer_replied，管理员公开回复answered，双方均可closed；历史in_progress只展示。已关闭只读，不自动重开，需要继续处理时另提工单。每次回复锁原工单，不覆盖旧正文；并发不同请求均保留，状态取最后一次提交角色。回复与结单竞争：回复先提交则旧关闭版本失效；关闭先提交则新回复409。重复已成功请求可读取原成功身份，不重复回复或审计，即使工单随后关闭。

本批不支持代登录写入，管理员必须使用后台公开回复入口署名。客户所有读写以当前启用主会话和tickets.user_id限制；他人工单及不属于本人的实例404，不能通过参数替换客户ID／角色／状态。关联实例只在提交时选定，不允许后续改绑；查询始终重核实例与工单客户相同，失配时隐藏实例，不泄漏其他客户信息。现有内部便签／转派记录不进入本批公开会话、总数或关闭版本；仅type=reply的归属一致作者可见。

每个写请求携带UUID request_key。复用ticket_replies新增可空request_key CHAR(36)、request_hash CHAR(64)，分别以(user_id,request_key)、(admin_id,request_key)唯一。指纹绑定动作、原工单／关联实例及正文；同键异参409。同作者先锁原users／admins行重核启用与身份，再读原请求并锁工单；为复用作者作用域防重，会短暂锁定兼载钱包余额的users行，或管理员行；事务仅本地短SQL，不锁实例、账单或流水，不调用上游。创建以首条回复的请求键定位原单，避免另一份提单防重表／字段。结单追加署名的固定纯文本记录，状态、closed_at、记录和管理员审计同事务；关闭重放须使用原键。新键关闭已关工单409，不额外留记录。管理员公开回复和结单按ticket.reply／ticket.close追加原admin_audit_logs，context仅记录回复ID和前后状态，无正文副本。

页面草稿及请求键存当前会话sessionStorage（按主Token指纹命名空间分隔），网络未知保留原键，可安全重试同一内容；改内容生成新键前须明确核对，不能不知结果就另提。成功后清草稿，按钮提交中禁重复；回复成功定位到最后一页，分页不自动吞掉输入。纯文本通过Vue插值与white-space:pre-wrap展示，不使用v-html／Markdown或自动链接执行。

## API与兼容

前缀 `/api/v1`；客户使用client中间件，后台使用admin中间件，响应no-store。

| 接口 | 语义 |
|---|---|
| GET /tickets；GET /admin/tickets | page/per_page（默认1/20，最多100），status可选；后台额外ticket_id/user_id/email/instance_id精确筛选 |
| GET /tickets/instances | 本人实例选择器，search按ID或名称字面匹配，分页本地查询，安全投影id/name/status |
| POST /tickets | title（1–150字符）、content（1–10000字符）、可空instance_id、request_key |
| GET /tickets/{id}；GET /admin/tickets/{id} | ticket、安全关联instance、version及按ID升序分页的public replies；page=last可取末页 |
| POST /tickets/{id}/replies；POST /admin/tickets/{id}/replies | content、request_key；返回ticket_id/reply_id/replayed |
| POST /tickets/{id}/close；POST /admin/tickets/{id}/close | expected_version（64位）、request_key；返回原关闭记录身份 |

内容必须有效UTF-8，拒绝空白、NUL／非法控制符和额外字段。标题单行，正文允许换行。筛选页码进入URL；未知状态、超限分页400，失效／跨身份401，禁用身份403，归属不存在404，旧版本／同键异参／关闭冲突409。

27张表保持，仅新增回复实体防重属性与唯一索引；旧行保持NULL且正文不改写。已有库先执行000009迁移再启用工单接口，无Worker改动或重启需要；本批不默认迁移M2／正式库。回滚不能删除已接受请求的防重记录。schema、字典、接口、架构、前端、README与路线图同步；运行前置与隔离证据见下节。
