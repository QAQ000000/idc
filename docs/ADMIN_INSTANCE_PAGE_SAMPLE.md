## 页面、权限和状态持有

顶部名称最多显示两行，完整名称在概览保留；显示实例名称／编号、本地状态、权益、到期日、IP、客户／商品及原任务／资金关联入口。服务异常、过期权益、价格／补差原门禁、读取失败和补差未知结果集中前移，切分区后仍可见。不把未显示警告当作无任务占用的证明，实际写操作继续由原服务裁决。

| 分区 | 内容与行为 |
|---|---|
| 概览与归属 | 默认区，完整客户、商品、上游资源与账期；长名称／邮箱／编号换行。 |
| 服务核对 | 原服务状态面板；超级管理员才有原只读核对按钮，其他管理员只读。无资源或驱动不支持时明确说明。 |
| 价格与补差 | 原续费价和手工补差面板独立提交、独立版本与审计。财务可读、超级管理员写；客服／运维只看权限说明，不挂载金融面板、不请求资金接口。 |
| 关联账单 | 原归属一致的账单状态、财务详情及任务入口；页内分页只读原接口，不改变URL或卸载其他面板。 |

分区使用 Element Plus 非懒加载 Tabs，状态由实例页内存与原业务面板持有，不靠 URL query 或新状态库。详情刷新不清空已挂载数据／表单，失败提示仍是上次资料；首次失败为空错误重试。更新成功显式刷新关联面板，防止价格与补差互相显示旧数据。不同实例／身份仍沿用原路由卸载与后端鉴权；不承诺跨 F5 恢复前端草稿。本页无凭据展示，不新增明文缓存或轮询。

## 独立提交与未知恢复

续费价仍用原版本确认，409／丢响应先重读价格与审计，再显式重新操作，不自动重复PATCH。补差草稿保留在本面板；普通取消清空，预览后要求明确余额结清确认，提交中不能关闭或重复提交。

补差结果未知保留原 `preview_token`、`request_key` 与确认参数；关闭窗口、切分区、分页或刷新详情均不清除。顶部持续提示，价格分区提供“恢复原补差结算”。重新打开只能核对并原键原参数重试，不允许修改原预览或另建操作。明确拒绝后才重新预览，成功后清除未决上下文、重读记录及关联价格。原接口本就支持重放成功账单，不新增幂等实体。

修改原因是长页难定位且旧补差打开函数会清空未知结算上下文；通过保留组件和显式重读解决，不新增通用状态机。成本增加四分区局部状态、面板摘要事件和两个重读入口；减少垂直寻找、路由重挂载与未知操作误建风险。

## 验收记录

### 已执行检查与证据

- 独立 MySQL／Redis／HTTP 完成 **1649 项业务检查（25 套）**，包含原权限、付款／代扣竞争、补差幂等和审计回滚；私有 PHP-FPM 在配置缓存前后均通过身份与金融权限检查。环境由 `REDIS_SERVER=/www/server/redis/src/redis-server python3 scripts/test_integration.py --browser` 创建，不读取 M2／正式 `.env`。
- Chromium **109 项页面检查**：交互恢复47项、状态／角色46项、收尾长标题与正常首屏16项。1440px 桌面、320×568／390×844 手机、768×1024／820×1180 竖屏平板完成四分区切换、表格内滚动、长字段、无能力、空账单、首次失败重试、旧版本拒绝、独立提交及实际 API 权限检查。
- 服务核对结果在详情重读与切分区后保留；未确认暂停／过期警告在所有分区可见。客服／运维不挂载或请求金融面板，直调金融接口被拒；财务只能读，客户 Token 不能用于后台查询。键盘方向键可切换分区。
- 补差提交中不能重复提交／关闭／Esc。真实隔离服务提交成功后主动丢弃浏览器响应，关闭窗口→其他分区→账单翻页→详情读取失败→恢复原结算，捕获的两次请求 **preview_token、request_key、confirmed 完全相同**；审计与账单只新增一次。原续费价面板同步更新；普通取消仍清空草稿。续费价丢响应仅重读已提交价格与审计，没有自动再次PATCH；并发旧版本不会覆盖新价。
- `vue-tsc`、ESLint（0错误／0警告）、Vite生产构建、27表字典同步和差异检查通过；构建仅保留原 Element Plus 主包超过500kB提示，无新增依赖。

使用同一独立资源记录改造前后截图。长字段／空结果／无能力分支由浏览器只读响应变体生成，角色与结算使用隔离服务真实校验；不把变体计为新增真实资源或上游验收。

### 操作路径与手机／平板变化

| 任务 | 原路径 | 样板路径与增加的交互 |
|---|---|---|
| 查服务 | 经过实例与归属大表格、关联链接后向下找面板 | 顶部先看状态与异常，再点“服务核对”一次。 |
| 调续费价／补差 | 继续滚过前面重型卡片，寻找两个独立入口 | 点“价格与补差”一次，沿用各自原弹窗、预览／确认与提交。 |
| 找账单 | 滚过服务、价格、补差后查表 | 点“关联账单”一次；翻页保持其他面板状态。 |
| 未知结算 | 原窗口内可重试，关闭再开会清掉原预览 | 任何分区顶部保持未知提示，回价格分区→恢复原结算→原键核验。 |

正常夹具中，价格分区入口在320／390／768／820px的文档Y坐标分别为473／399／364／333px，均无需先滚过业务面板；异常提示可占用更多首屏空间，不为凑位置隐藏阻断。分区与分页不改URL，也不承诺F5保留当前分区／页码。
