# M2 后续：同上游固定商品续费（2026-11-08）

## 变更原因与边界

首条真实新购已在 `290c9b7` 验收。本批在同一 Worker、付款服务和实例页面上增加一个原账期的续费，不新增表、不扩展通用配置或第二个上游，不强迫新购驱动实现续费。原新购请求及付款接口保持兼容。

`RenewalDriverInterface` 是明确可选能力；首个实现为魔方财务。增加只读预检、一次续费执行及只读续费调查。核心只引用 `app/Plugins` 契约，协议及自动解挂差异留在具体插件。

## 账单、付款与周期

- `POST /instances/{id}/renew` 必须带当前看到的 `base_due_date`（UTC 秒精度字符串），只买一个原 `billing_cycle`。同周期请求重放返回原单，包括付款和交付之后，不能变成下一次购买；月/年付不通过任意月份参数互换。
- `cycle_marker=r:{instance_id}:{原到期日YYYYmmddHHMMSS}` 保留已付周期的唯一凭证。未付取消、不可逆销毁保护退款同步清空标记；续费取消不销毁原实例、不返还新购库存。
- 固定本地报价取 `COALESCE(override_price,recurring_price)`，`quote_expired_at=NULL`。出账前只读预检上游账号范围资产、商品、账期、续费价格及上游原/目标到期日，并要求上游自身自动续费关闭，避免两套代扣并行；不产生上游账单、不扣款。上游成本与本地售价值分别冻结，预检不改实例固定售价。
- 同一实例锁下，账单 `unpaid -> paid` CAS、钱包扣款或渠道实收凭证、累计消费、从**原本地到期日**顺延一个自然月/年，以及唯一 `renew` Outbox 同事务提交。月末/闰年夹紧；日期快照统一秒精度，避免 MySQL 参数运算的微秒表示破坏比较。
- 本地已购权益与上游履约分开。上游采用其账户接口返回的原日期和单周期 duration，不能把本地新购交付确认时刻强行覆盖上游既有日期。执行前日期/价格变化停止自动推进；未知结果只读反查目标日期，不再生成上游账单或再次付款。
- 相同网关交易回调不二次收款；不同真实重复款、过期归属或非销毁门禁的实收只入钱包，不二次顺延。不可逆/主动销毁时，未付续费单按 SC-L02 一次转 refunded、释放周期标记，实收仅一笔 refund_to_balance；没有实际扣款的余额/代扣请求不凭空退款。

## 暂停、销毁与恢复

本批自动流程支持 active 和 suspended/billing。魔方收取续费款可能自动发起解除暂停，且客户端不能可靠区分上游暂停原因，因此对 compliance/abuse/manual 暂停采取**拒绝自动续费并交人工处理**的当前策略；不会用支付绕过风控。未来若支持保留暂停的续费，必须先验证具体驱动能保留上游安全状态。

欠费暂停付款后保持 suspended，任务中冻结 `needs_unsuspend=true`。魔方插件在同一 renew 执行中付款后观察上游到期日和 Active；没有确认恢复则保持调查和本地暂停，不假设成功，也不拆分可乱序领取的独立 unsuspend 任务。超过观察窗口进入人工门禁。

只有 pending 且 termination_reason=billing_overdue 的销毁任务能在正常续费付款事务中取消，递增令牌并保留终止标记；运行中、调查中、人工核验的销毁即使租约已过期仍阻断；主动退订和安全销毁不撤销。其他未决任务与云消费退款冻结继续使用现有 TaskGate。

人工裁决允许在证据、旧令牌、enabled super_admin 门禁下重试或确认原资产续费完成；不接受把续费资产换成另一个 ID。新购的 cancel_compensate 不复用于续费，避免终止原有付费资源；续费资金补偿、原路退款仍需后续独立审阅，未知结果先调查。

## 出账、代扣与部署

`renewals:generate` 每小时扫描提前 7 天及已到期、仍具备续费条件的资源，只创建/返回唯一未付账单。`renewals:debit` 每 15 分钟独立扫描，持锁重检 auto_renew、窗口、实例/任务/退款门禁和余额；钱不够保留原单，后续充值后下一次扫描可继续。关闭自动续费不影响手动付款。

这两个命令只登记到 Laravel 调度，不安装系统 cron，不修改生产配置。当前没有真实充值事件订阅，秒级充值唤醒延期；15 分钟扫描是本批恢复路径。轮询按 ID 分页，避免前一批阻断订单长期饿死后续订单。实际调用上游仍由现有 outbox:work 独立执行。
