# M2 本站实例控制台

## 实施契约（2026-11-08）

实例详情进入 `/instances/:id/console`；Vue 使用本地打包 noVNC，页面、静态资源和 `/console/ws/<随机票据>` 均走本站。禁止加载供应商页面、iframe、重定向或向客户返回上游 URL、临时密码、host_token。供应商特有响应由可选 ConsoleDriverInterface 解析，核心仅处理中立 DTO，不引用具体插件。

客户使用独立主登录 Token 调用 POST `/api/v1/instances/:id/console`。校验当前启用客户、本人归属、已交付未过期、无冲突任务及驱动能力；模拟登录/管理员作用域不允许。返回 60 秒有效、一次性随机票据路径，不是登录凭证。WebSocket 握手同时校验原主 Token（子协议头传递，不放 URL）、精确 Origin、票据与当前归属/状态；票据通过 Redis GETDEL 消费，内部内容 AES-256-GCM 加密。Redis 不可用拒绝签发/连接，不影响原 Outbox。

独立 PHP CLI 中继使用成熟 WebSocket 库，绑定 loopback，本站反向代理转发升级；不占用 FPM 长连接，不增 Node 后端或业务表。最长连接 15 分钟且不超过主 Token 到期，每 15 秒重检客户/实例/任务门禁；断线须重新授权，无静默重连。上游目标必须在服务端配置的精确 host:port 白名单，强制 wss、TLS 校验，DNS 解析只允许公网并固定连接 IP 防重绑定（隔离测试显式豁免 loopback）。限制连接数、帧/缓冲、握手时间并双向关闭连接。

服务端桥接 RFB 3.8 的 None/VNC challenge 认证，上游密码只在服务端使用；客户侧 None 认证仅发生在本站主登录与票据握手成功以后。其他认证模式拒绝，不降级到供应商页面。远端桌面本身的画面/客户输入不做脱敏，本机制保护连接元数据和供应商凭据，不保证客户操作系统不会显示供应商标识。

不调用开关机、不记账、不修改实例/历史任务；授权不是生命周期任务，不写 Outbox。日志仅记录安全错误码，不包含 URL、票据、子协议、上游返回及桌面数据；反向代理 `/console/` 禁用访问日志。正式环境须 HTTPS/WSS，M2 loopback 可 HTTP/WS。

## 本轮验收证据（2026-11-08）

- 隔离全回归通过 562 项（原 516 项 + 35 项控制台权限/凭据/协议检查 + 11 项实际 HTTP/WS/RFB 联通检查），独立运行守护另通过 22 项。新增覆盖：主登录与票据分离、管理员/模拟登录/越权/封禁/到期拒绝、排队和未知任务门禁、Origin、会话绑定、过期与重放拒绝、私网目标拒绝、Redis 密文、独立 noVNC DES 向量、分片认证、标题替换及双向二进制帧。短主会话过期会主动断开已建连接。PHP-FPM 配置缓存前后检查保持通过。
- 前端 lint、TypeScript、生产构建通过；生产构建保留原 Element Plus 主包体积提示。noVNC 作为单独路由包加载，不把第三方 UI 页面引入本站。DDL 字典 27 表同步检查与 Git 空白检查通过。
- M2 接入 `jianyun-m2-console.service`，PHP CLI 独立守护并只监听 127.0.0.1:18213；原 18212 Redis 保留。API 使用相同控制台配置重新启动，原 Worker/调度继续 active。无 VNC 数据库迁移，私有白名单/凭据/备份不入库。
- 真实实例 3 经本站签发、WebSocket、服务端密码认证，浏览器读到 1024×768 Debian 12 登录画面。HTTP 资源 origin 仅 `http://127.0.0.1:18211`，VNC WS 为同本站 `/console/ws/<ticket>`，iframe 数量 0；无浏览器供应商域名请求。一次上游临时不可用被拒绝后，手动重新签发成功，未触发任何购买/电源动作。
- 1440px 桌面与 390px 移动端完成画面检查；移动端 documentWidth=390，画布缩放为 358px，无页面横向溢出。热更新离开旧组件时连接关闭，重新进入仍需显式授权。真实浏览器显式断开后退出登录，再直达该路由被拦截到 `/login?redirect=/instances/3/console`。

当前只支持已核验魔方标准 WebSocket/RFB 3.8 None/VNC 认证模式；外置 HTML 控制台或其他认证协议拒绝。正式 HTTPS/Nginx、长时高并发和 15 分钟完整实时时长尚未做真实环境验收；会话到期关闭已在短时隔离连接中验证，服务端上限/门禁由代码执行。远端系统内出现的供应商品牌不在连接元数据隐藏范围，SSH 与网络性能验收不属于本批。
