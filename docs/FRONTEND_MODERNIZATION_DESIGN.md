## 布局和视觉

保留单一 Vue 3、Element Plus、Pinia、Router 和 fetch；不引入第二套组件库、字体服务、图表或布局依赖。浅灰背景、白色面板、蓝色主操作、深色正文与清晰边线，状态始终配文字，避免仅靠颜色辨识。装饰只采用本地 CSS/SVG。

公开页面采用顶部品牌/导航与宽屏内容区；客户和后台复用同一外壳，桌面显示角色对应侧栏，窄屏使用 Element Plus 抽屉。客户和管理员会话、退出行为保持独立；后台身份不作为客户身份。只展示已实现入口，不放充值或资金查询占位按钮。VNC 保留尽可能宽的画布。

全局内容最大宽度 1280px，间距以 8px 递增，面板圆角 12px，主操作明确且数量受控。小于 1024px 切换抽屉，390px/320px 单列显示，长名称/IP/证据换行，表格只在自身区域滚动。保留键盘焦点、语义标题、按钮可访问名称和跳至正文入口；遵循减少动画偏好。
