## 变更原因与范围

后续于 `75c1fa6` 的按需加载。三轮同资源对照中，完整电源读取平均11.7秒，单查电源5.5秒；本站额外处理约0.1秒。展示无需每次串行读取资源和控制信息，因此拆分展示、准备及执行；保持原完整接口兼容。没有新表、迁移、资金操作或 Worker 行为变更，27表保持。

## 接口与授权边界

| 接口 | 用途 | 上游及缓存 |
| --- | --- | --- |
| runtime?view=tasks | 当前本地门禁与任务 | 原 MySQL，无上游，无令牌 |
| runtime?view=observation | 上次电源观察 | 120秒 Redis；不存在返回unknown及空时间，不发上游 |
| runtime?view=state | 最新展示性电源读取 | 魔方仅对原host绑定调用status，合并同资源在途读取；不返回actions或operation_token |
| runtime（full） | 用户显式“准备电源操作” | 原完整实时能力、绑定核对和120秒令牌，不缓存 |
| reinstall?view=images | 选择用镜像列表 | 5分钟脱敏投影缓存，仅images／password_mode／data_disk／时间及状态，无令牌 |
| reinstall（full） | 清盘确认前准备 | 原实时读取及120秒令牌；列表变化要求重新确认 |

上述展示模式均先验证本站认证、归属、实例有效性及现有任务／资金门禁，缓存命中也重核原上游连接状态。网络读取前后重核绑定、版本及门禁；不在网络等待期间持有数据库行锁。停用上游、到期、绑定／配置／任务变化不沿用旧观察。核心仅依赖可选 PowerObservationDriverInterface，魔方status映射留在插件；不支持此接口的驱动显示unsupported，不能凭展示授予电源能力。

魔方本机源码 `Host::status` 自身验证上游账号拥有该host且服务Active；因此展示可省去hostinfo及header。核心不猜测其他驱动的归属语义。操作准备、提交、Worker原始实时校验、执行令牌、Outbox及未知调查均不变。

## 缓存与失败

Redis缓存按应用密钥／数据库、连接及密文凭据版本、原实例绑定／归属／状态／账期／配置与最新任务身份及状态隔离。只缓存严格DTO投影，不能包含原header、主机密码、供应商地址、操作令牌或任务事实。返回HTTP no-store，浏览器内展示观察时间及“上次观察”，后台独立更新；失败保留已有观察并明确失败，不将旧观察变成最新成功。

同键只读读取使用60秒Redis租约合并，其他请求最多等待42秒，共享本次结果；失败不在等待请求中补发上游，显式重试由用户后续查询决定。发布与解锁均比较随机所有者，过期读取不能覆盖新缓存或删除新锁。Redis失败退为本次直接只读查询，不重试已经执行的loader。该锁只减少展示流量，不能释放任务占用或做操作授权。

魔方Token按应用密钥／数据库／连接及凭据版本隔离，并加密存Redis；仅信任HTTPS登录返回Token中的明确exp作为缓存期限，不把此解析当作本站身份验签。有效期取上游剩余期限减30秒与300秒的较小值；未知期限不缓存。当前上游实测exp剩余7200秒。Token过期或认证拒绝使旧缓存失效；只有明确白名单只读接口允许更新Token后重试一次。任何变更请求不自动重放，仍按原未知结果语义处理。Redis不可用时正常登录，认证失败不会降级成功。并发不同资源首次登录可能各执行一次；本批不引入全局登录任务。

## 页面行为

稳定页壳、原任务轮询及未知请求键保持。电源初始化先读取本地门禁，再读缓存观察与最新状态；不准备操作能力。点击“准备电源操作”后取得当前允许操作，再沿原确认／一次提交流程。观察失败不阻断独立VNC，也不能恢复旧动作。重装镜像仍只在维护区展开时读取，点击重装先实时准备，再比较镜像及规则并二次清盘确认；变化或失效不提交。提交及Worker继续原实时核验。

HTTP／前端需加载同版；旧客户端完整模式保持；本批不要求重启金融或邮件Worker。M2原金融／邮件／财务调度暂停状态保持，不恢复旧业务任务；真机仅做只读计时，不发电源或清盘。
