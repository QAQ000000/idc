# 客户本地选配预览与提交复核（2026-11-10）

## 范围与契约变更

为消除选配时反复等待上游，新增公开POST `/api/v1/products/{id}/preview`，输入同calculate。`PRODUCT_LOCAL_PREVIEW`默认关闭；开启后，仅已通过完整发布、观察hash匹配当前快照且未过期、插件明确支持的组合返回本地预览。核心只依赖可选LocalPreviewDriverInterface，魔方计价与输入规则留在插件，无新表或迁移。

支持时返回原Quote安全字段及`pricing_mode=local_preview`，不公开成本、矩阵、上游身份或诊断hash。不支持／关闭／缺失／过期时只返回`pricing_mode=online_required`，不带金额或确认令牌，且本接口始终不发上游请求。此处缺失指完整价格矩阵或成功观察缺失；若本地销售周期／配置本身缺损到不能安全解释，则直接拒绝。原calculate继续完整在线核价，追加`pricing_mode=online`。不猜配、不返回默认零价。

本地令牌使用独立用途前缀，绑定当前商品成交指纹、周期、选择、首期／续费售价及密码规则；有效期不超过5分钟和当前快照有效期。它仅表示客户看过预览，不能替代在线核验。checkout仍先按原请求键恢复，再做完整在线预检，最后原锁内校验、创建账单或扣款与Outbox。实时金额／配置／规则变化时拒绝本地确认，不写资金、实例或账单；原Worker预检不改。

## 页面与异常路径

原结账页400ms防抖、单在途和迟到保护保持；先请求preview，新组合直接在本站算价。online_required后显示“正在实时核价”，再调用calculate。页面明确区分“选配预览，提交时实时复核”与在线确认，不能把预览显示为最终成交。

提交前变更选择立即清空旧确认；提交中禁止改动配置、账期及账户输入。409后保持原请求键，强制获取在线报价并要求用户再次点击确认，不自动提交；响应未知时按原键重试，禁止自动重购。重新获取报价不生成新下单意图。手机吸底条和桌面摘要共用状态及金额，在线失败清空报价，不保留旧预览成交。
