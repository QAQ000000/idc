# 实例详情独立加载与按需能力读取（2026-11-10）

**后续增量**：本页保留75c1fa6的历史结果；展示缓存、魔方Token复用及新展示／准备接口见[M2_INSTANCE_DISPLAY_CACHE.md](M2_INSTANCE_DISPLAY_CACHE.md)。后续已实现这些原延期项，不修改本页历史计时。

## 范围与原因

仅调整客户 `/instances/:id` 的读取编排。旧页的电源／重装能力都在挂载时读取上游；两个面板把“尚无能力响应”视为共同阻断，互相变化又触发完整查询。即使基础资料来自本站，VNC 仍等待隐藏的重装区；M2 单进程开发 HTTP 还会让上一轮远端请求堵住下一次本地资料请求。

保持单 Vue／Element Plus、稳定页壳、原 Provider 契约和实例／任务事实。没有新增缓存、登录 Token 复用、表、迁移或 Worker 行为；不调整资金、资源绑定、账期及重装完成证据。

## 读取及门禁

| 内容 | 读取时机 | 失败影响 |
| --- | --- | --- |
| 基础资料 | 原本站详情接口 | 保留上次资料、暂禁操作；面板不卸载。 |
| 本地门禁／任务 | 电源与重装面板初始化各读 `?view=tasks` | 未知或失败继续阻断，原未决意图保持。 |
| 电源状态／能力 | 本地门禁明确且无占用后独立读取原完整 runtime | 显示正在查询／未知／失败及已有观察时间，不能使用旧动作；不将远端读失败当作全页任务占用。 |
| 重装镜像／能力 | 系统维护分区内显式展开重装区域 | 只影响重装表单；未展开及其他分区不请求镜像。 |

电源 `GET /api/v1/instances/{id}/runtime?view=tasks` 新增与重装相同的轻量模式，仅返回 `blocked` 和原白名单 `tasks`，不访问驱动、不返回能力或令牌；缺省及 `view=full` 兼容原完整返回，其他值（含数组）400。两种模式继续本人认证／归属、实例优先锁、TaskGate 及所有 pending／资金门禁，响应 no-store。未启用、过期或无能力不能因为轻量模式而获得操作确认。

VNC 入口不再等待远端电源与镜像响应，仍要求本地门禁已核对、原权益／状态允许且无提交或未知意图。真正签发连接、提交电源／重装、续费及 Worker 执行继续使用原服务端权限、当前事实、操作令牌与预检；前端可用状态不是授权凭证。

## 生命周期与恢复

面板持续挂载。每面板只有一个串行定时器；已有本站未决任务或丢响应意图每15秒仅读本地任务，隐藏分区也继续。没有本站未决任务、只读到远端 transitioning 时，电源保留最多2分钟的原远端观察窗口。切分区不新增轮询或 POST，结果未知不新建请求键、不重复发重启／重装。

本地占用／任务变化立即失效旧能力；在途能力响应还要比较页内失效版本，不能用迟到响应恢复旧令牌。任务结束后电源重新读取能力；重装仅在维护区已展开时重新取得镜像／令牌并清除清盘确认，否则推迟到下次展开。切回已有且仍有效的镜像表单不重复读取；后台仍以120秒确认期限和实时预检裁决。手动刷新合并同类在途读取。

凭据仍由独立查看区域显式读取；折叠、切区、离开视口、后台、pagehide、路由离开、重装开始及资料重读时立即清除明文并使迟到响应失效。重装受理／执行结束和系统可登录继续分别表达，不改变供应商结构化字段的真实验收边界。

## 兼容与复杂度

修改 InstanceController／InstancePowerService、两个原面板及 InstanceView；魔方插件只扩展原脱敏阶段耗时日志（resource／control／power_status），不增加具体驱动与核心的相互引用。客户端需先部署兼容 `view=tasks` 的后端；旧客户端仍可调用完整模式。27表及SQL字典保持，HTTP／前端需加载同版，不要求重启业务 Worker。

增加本地门禁与远端能力分别记录、按需展开状态及迟到能力版本检查；删除初始化隐藏镜像请求、互相触发的完整远端读取及远端失败对独立入口的阻断。短缓存和登录复用继续延期：本次首先消除重复调用，上游实际单次控制／状态仍较慢，不把旧观察或旧令牌作为新授权。
