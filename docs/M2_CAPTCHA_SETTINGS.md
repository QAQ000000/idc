# 验证码策略后台

## 范围和接口

独立页面 `/admin/captcha` 紧凑展示登录、注册、找回密码，三个场景分别保存。只有当前启用的超级管理员可 `GET /api/v1/admin/captcha-settings`、`PATCH /api/v1/admin/captcha-settings/{scene}`；事务锁定管理员后重核角色、二次认证限制与会话版本。首批仅 `builtin_image` 和 `mode=always`，没有第三方驱动、失败次数模式或动态限流配置。

GET返回 `scenes`，每场景有 `enabled:boolean,driver,mode,configured:boolean,version`。PATCH为完整 `enabled,driver,mode,expected_version`；拒绝未知字段、场景或未实现模式。响应 `{saved:true}`，旧版本409；配置与审计失败整体回滚。公开 `GET /api/v1/captcha/config?scene=...` 继续只返回该场景当前公开配置／挑战，不返回后台版本、审计、其他设置或密钥，响应 no-store。

复用 `system_settings.captcha_scenes` 的单个JSON对象，只替换目标场景并保留其他原内容；三个场景独立HMAC版本，包含本场景原记录及最新 `captcha_configure` 审计ID。同值保存也推进本场景版本，其他场景保存不改变本区版本。审计 `target_type=captcha_scene`，target_id 按 login/register/password_reset 映射1/2/3，context仅scene与before/after公开策略。无表、字段、迁移或密钥新增。

## 安全与兼容边界

- `login`同时控制客户和管理员登录，页面就近明确说明；两个登录端点限流独立。注册只影响客户注册；password_reset只影响申请邮件，不替代重置链接的独立校验及限流。
- 未配置整行或缺失场景默认开启本地图片／always。历史仅 `enabled` 的正常配置补默认driver/mode，保持兼容；显式null、错误类型、未知属性／场景、未实现模式或不可用驱动均拒绝，不自动解释为关闭。关闭配置也先验证驱动／模式。单场景内容损坏拒绝该场景，其他有效场景仍按原规则校验；根对象损坏阻止读取。后台整体读取失败不开放无版本表单，不提供隐式修复开关。
- 每次提交由中间件重新读取当时已提交策略，不信任页面的enabled。旧关闭页遇开启返回422并获取新挑战；旧开启页遇关闭按当前关闭策略继续，但仍计入基础限流。策略读取前已经准入的并发请求不会被追溯撤销。未额外建立挑战版本、撤销表或逐次保存的挑战清扫；在当前驱动／模式下仍有效的旧挑战按原5分钟、场景／IP、单次消费规则处理，不承诺一次开关即清空所有已发挑战。
- 内置图片继续在插件内生成，Redis原子取出删除；错误答案、错误场景或错误IP也消费挑战，重复使用拒绝。核心只依赖注册器／接口，不访问插件内部存储格式，不导入具体驱动。前端读取失败／非法挑战不提交，刷新与场景变化会使旧响应失效。
- 客户HTTP登录10次／60秒／可信IP，注册5次／60秒／可信IP，包含失败、无效参数和验证码拒绝。独立中间件位于验证码之前，Redis Lua原子计数＋首次过期，不会在并发检查与计数之间超发。返回429且不执行密码哈希、用户写入或验证码消费。按首次请求起算固定窗口，不是滑动窗口；共享出口IP共享额度，成功不清零。
- 原管理员10次／分钟／IP、找回申请10次／小时／IP及邮箱冷却／频次限制继续保留。新限流只用于公开HTTP端点，不限制内部CLI初始化；无测试环境运行时豁免。关闭验证码后限流仍运行，Redis不可用直接拒绝请求，不能回退到无验证登录／注册。挑战生成或校验Redis异常同样拒绝。限流状态只在Redis，不参与资金／资源事实或业务占用。

## 页面和保存恢复

三个独立场景卡片显示影响、已保存状态、开关、固定模式及限流说明。每区独立草稿、版本、保存和核对；不新增通用安全策略编辑器，不并入站点基础资料。复用useSettingsDraft，409／响应丢失先只读GET，不自动PATCH；相同版本的未知提交继续阻断，版本变化且字段相同只说明当前值一致。显式采用当前值或保留草稿后采用新版本才能开始下一次提交。有未保存／未知状态离开提示，手机保持单列。管理员登录回跳允许现有站点、支付及本次验证码设置路由。

## 变更、成本与验收

原CaptchaService在enabled=false时提前返回，可能跳过损坏的模式／驱动检查；客户登录／注册没有独立HTTP限流。本批补齐严格读取、既有配置管理、原子HTTP限流及挑战组件的迟到响应保护。保留原插件接口、挑战格式、场景和鉴权流程，不加表／新驱动／第三方API，不改资金与实例。冻结契约影响为损坏配置现在明确拒绝、客户公开端点新增429，以及旧页面按当前策略重新验证；运行接入需加载新HTTP代码，无Worker或迁移需求。
