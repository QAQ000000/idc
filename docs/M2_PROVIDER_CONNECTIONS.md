# 已有驱动的上游接入管理

## 本批契约

同一 Vue／Element Plus 后台 `/admin/providers`、`/admin/providers/new`、`/admin/providers/:id`。所有当前启用管理员只读名称、驱动、启用／配置状态、关联商品与实例数量、分页操作审计；超级管理员才能读取创建表单、创建、改显示名称和验证连接。凭据、密文、地址、账号、原始 Schema／异常不回显；字段只显示已配置／未配置。详情关联原商品／实例列表及商品导入，不另建业务页面。

连接 ID 是资源命名空间。网页不允许替换 driver、endpoint、credentials、status，不提供删除或资源迁移。换账号／地址新建连接，已有商品／实例／任务继续绑定原连接。仅改显示名称需要 expected_version，版本以原行和配置写入审计计算；并发／过期版本 409。创建带 request_key 和驱动目录版本，当前管理员下同键同输入重放原连接、换输入 409；凭据仅以 HMAC 参与比较，不写审计。连接创建／改名与审计同事务、锁内重查超级管理员；不新增表或字段。

独立 ProviderConnectionService 承担驱动连接参数验证、加密和连接持久化；原 CLI 安装器复用它并继续在原事务写商品／支付，网页不调用 CLI 安装器，不碰支付配置。可选 ConnectionConfigInterface 由已安装插件提供字段描述及验证，核心无具体驱动引用；不强制未实现插件增加空实现。魔方使用 endpoint／username／password，人工驱动无需远端参数且不支持在线 Schema 验证／导入。

超级管理员属于受信基础设施配置边界，可指定 HTTP(S) 上游（含内部服务）；这是管理端网络访问能力，不开放给客户或普通管理员。只接受无 userinfo／query／fragment 的基础 URL，不跟随跳转，沿用驱动超时／报文上限／TLS 校验；验证只能使用已保存连接与正整数商品编号、已支持账期，不接受任意路径／方法／请求体。出站网络隔离仍由部署控制。创建不联网，不以配置齐全承诺连接可用。

验证复用 ProductSnapshotService.prepare 的只读 Schema／报价路径，默认选配、单账期；只返回成功标识、配置项数量、CNY 首期／周期参考价和时间，异常统一脱敏。网络调用不持有数据库锁，结束后重查连接版本和身份，结果／失败操作留本地审计；不购买、不续费、不支付、不回写商品快照。此处“只读”指上游业务读取，认证可能生成上游会话，本地会记审计。失败不改变连接状态或重发业务动作。

## 接口与页面状态

保留原 GET `/api/v1/admin/providers` 选择列表数组响应；新增 `/admin/provider-connections` 分页列表与创建、`/:id` 详情和改名、`/:id/verify` 验证、`/admin/provider-drivers` 表单目录。列表支持名称字面子串／driver／status，page 1–100000、per_page 1–100；详情 audit_page 每页20。所有响应 no-store；匿名／客户401、禁用或越权403、非法输入400、缺失404、版本冲突409。

页面筛选／分页留 URL；加载、空结果、失败重试、404 独立展示；手机筛选单列、表格内部滚动。创建发送后清除秘密输入；响应丢失保留本次请求键，重新输入相同连接参数可找回原连接，不自动创建新连接。改名／验证发生409时须刷新详情重新确认。验证成功提供现有商品导入链接并预选 provider_id，预览／导入原门禁及新商品默认下架保持。
