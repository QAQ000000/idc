# JianYun (简云) · 统一单前端架构设计规范 (Frontend Specification)

本文档定义了 JianYun 的前端工程架构、技术选型、目录规范、交互模型与权限路由设计。

**充值与资金查询已接入**：沿用公共布局和标准 Element Plus 页面，客户 /wallet 查询余额／本人流水、创建充值单，原 /invoices/:id 支付／取消及确认到账。后台 /admin/finance 与 /admin/finance/invoices/:id 只读关联账单、实收凭证和流水；当前 finance/super_admin 可读，后端重核权限。筛选／页码进 URL，付款返回不触发入账，迟到款与父单状态分开展示；加载、空结果、错误重试及手机单列见 [充值契约](M2_WALLET_FINANCE.md)。

> **选型确认（2026-11-07）**：用户确认 PHP 8.4 + Laravel 13 + MySQL + Redis + 单一 Vue 3 前端 + Element Plus，整体决策见 [技术栈决策](TECH_STACK.md)。M0 已建立 `web/` 工程，完成公开商品、注册登录、下单、账单查看/余额付款/取消；其余页面按路线图推进。

> **2026-11-08 增量安排**：现有功能手动验收完成后，先整理公共布局、商品页与实例详情，用户确认两个代表页后开发余额充值与后台资金查询，再逐页整理。视觉、路由、状态、移动端与验收记录统一在 [前端整理设计](FRONTEND_MODERNIZATION_DESIGN.md)，不等待全站精修。原权限、支付与任务契约保留。

**竖屏操作路径增量**：实例状态／VNC／电源前移，辅助信息默认折叠且保留组件查询与互斥；结账在小于 1024px 使用动态占位底栏和摘要抽屉，复用原表单、报价与幂等键；后台任务将高级筛选收进抽屉，URL 已生效条件与草稿分离。320／390px 手机、768／820px 竖屏平板的操作路径、截图和验收边界见 [竖屏记录](MOBILE_PORTRAIT_UX.md)。

## 一、 技术选型与设计原则

### 1. 核心技术栈
- **构建工具**：**Vite**（实施时锁定与 Vue 3、TypeScript 兼容的稳定版本）
- **开发框架**：**Vue 3 (Composition API / `<script setup lang="ts">`) + TypeScript**
- **UI 组件库**：**Element Plus**（已定案，统一采用其布局、表单、表格、弹窗及反馈组件）
- **样式策略**：优先复用 Element Plus 组件与主题变量，仅补充必要的少量页面样式；Tailwind CSS 不作为首版必需依赖，不并行引入另一套 UI 组件体系。
- **状态管理**：**Pinia**
- **客户端路由**：**Vue Router 4**
- **接口方式**：通过统一 REST API 客户端连接 Laravel 后端，保持前后端业务边界；不引入 Inertia 或第二套前端。

### 2. 首版交付策略

优先采用标准 Element Plus 布局、表单、表格和弹窗，通过复用业务组件减少重复实现。首版以一致、可用、易维护为验收重点，限制自定义视觉和反复改版，不为页面换肤扩大依赖。

按纵向业务闭环逐步交付：先完成一个商品的选购、付款、交付状态与实例查看，再按路线图扩展其他业务页面；每个闭环同时验收 API、权限及加载、空数据、失败和重复提交状态，不能只完成静态页面。目录中的页面表示规划范围，不要求首版同时建设全部页面。

### 3. 核心架构：统一单应用 (One App Architecture)
> [!IMPORTANT]
> **绝对禁止多端分散（严禁同时维护多个独立前端项目）！**
> 整个系统只维护一套位于 `web/` 的统一前端单页应用（SPA）。

```text
                               ┌─────────────────────────────┐
                               │     统一单前端工程 (web/)   │
                               └──────────────┬──────────────┘
                                              │
              ┌───────────────────────────────┼───────────────────────────────┐
              ▼                               ▼                               ▼
     【公开访客态 (Guest)】        【客户登录态 (Client)】        【管理员登录态 (Admin)】
   • 免登商品选购大厅             • 我的云服务器资产管控         • 用户管理 (一键免密模拟登录)
   • 动态规格计算与价格预览       • 实例开关机/重装/VNC          • 实例运维中心 (一键改价补差)
   • 登录 / 注册 / 找回密码       • 自主续费与变配补差           • 上游节点配置 (动态表单)
                                  • 财务账单支付与充值           • 任务发件箱监控与重试
                                  • 售后工单沟通                 • 全站财务流水与退款审计
                                  • 推荐返利与佣金提现           • 工单客服处理中心
```

## 三、 关键前端交互与组件规范

### 1. 动态规格配置项渲染器 (`ConfigOptionRenderer.vue`)
- **职责**：接收来自后端 SWR 缓存返回的 `config_schema` JSON 数据，自动判断类型：
  - `type: 'slider'` $\rightarrow$ 渲染滑动条组件（用于带宽 1~100M、数据盘 20~1000G）；
  - `type: 'radio'` / `select` $\rightarrow$ 渲染卡片单选框（用于 1核2G、2核4G、4核8G）；
  - `type: 'os'` $\rightarrow$ 渲染操作系统镜像选择器（支持 Windows / Linux 分组切换）。
- **实时响应**：选项变动时，实时触发本地价格联动计算，保证用户操作零卡顿。

### 2. 状态徽章与色彩体系 (`StatusBadge.vue`)
全站统一遵循企业级云服务语义色彩（浅色背景 + 高对比深色字，满足 WCAG 规范）：
- **运行正常 / 已支付 / 成功 (Success)**：浅绿底背景 (`#EAFBF3`) + 深绿文字 (`#097A43`)；
- **欠费暂停 / 待支付 / 审核中 (Warning)**：浅橙底背景 (`#FFF6E5`) + 深橙文字 (`#805200`)；
- **已销毁 / 已失败 / 已退款 (Error)**：浅红底背景 (`#FFF1F0`) + 深红文字 (`#BF3128`)；
- **待开通 / 执行中 (Info)**：浅蓝底背景 (`#E8F1FF`) + 深蓝文字 (`#0E4FCC`)。

### 3. 运维改价补差弹窗 (`PriceOverrideModal.vue`)
- 管理员点击实例列表的【改价/变配】时唤起；
- 输入新的月付价格，系统自动根据到期日折算剩余天数应收差额；
- 支持一键勾选【从用户余额划扣】，确认后提交，自动刷新表格，极大提升日常运维效率。

- **推荐：`@wangeditor/editor-for-vue`（或 `@tiptap/vue-3`）**
  1. **旧数据 100% 兼容**：原生吃进 HTML，旧库的 118 篇新闻直接放进去，原汁原味展现和编辑，零迁移痛苦；
  2. **轻量美观**：纯 Vue 3 组件，界面清爽现代，体积仅几百 KB；
  3. **自带常用能力**：支持图片上传/拖拽、代码高亮、表格、标题格式化，开箱即用；
  4. **前端安全与防 XSS**：配合 `DOMPurify` 库对展示内容做自动清洗，彻底杜绝恶意脚本注入。

## 四、 响应式与跨端适配 (Responsive)
- **桌面视口 (>= 1024px)**：标准侧边栏布局，高密度信息表格；
- **移动端视口 (< 1024px)**：侧边栏自动收缩为底部/汉堡抽屉，表格自适应折叠为卡片流视图，保证手机随时随地开机、续费、改配置。


## 五、 选型确认提交的历史契约调整记录

- **原因**：按用户于 2026-11-07 确认的技术组合定案 Element Plus，减少组件选型、视觉定制与多线 UI 开发成本。
- **影响**：前端技术栈、目录示意与首版交付策略；保留单 `web/`、Vue Router、Pinia、REST API、业务组件、权限与响应式约束。
- **兼容影响**：移除 TDesign 二选一和 Tailwind 必选假设；当前前端尚未落地，无已实现前端代码需要迁移，不改变后端领域或支付/Outbox 契约。
- **验证边界**：仅做文档差异与链接等静态检查，不安装依赖、不生成前端工程、不运行服务或数据库；运行验收待对应闭环实现后进行。


## 六、 M0 当前实现与边界

使用 Element Plus 标准组件及中文语言包，一套响应式布局；API 客户端采用浏览器 fetch，无需为当前少量请求额外引入 Axios。Pinia 管理账户，Bearer Token 放当前标签页 sessionStorage，主机密码、下单请求键和报价确认令牌只放表单内存。验证码组件根据后端 type 分派，当前仅实现已安装的 image 类型，其他类型拒绝提交而非放行。401 清理身份并在客户路由引导登录；登录 redirect 只允许站内路径。

M0 时账户找回密码、后台及退款页面尚未交付；当前已补齐客户找回密码、管理员任务/商品入口及实例列表/详情，退款页面仍未实现。首次下单网络失败后原表单重试复用 checkout_key；刷新/关闭购买表单会失去请求键；当前可在“我的账单”找回已落库原单，仍不承诺恢复尚未获得服务端账单编号的原表单，不把按钮禁用当作服务端幂等保障。浏览器验证使用独立测试库，临时关闭验证码以验证业务流程；启用验证码的接口生成、场景隔离和单次验签由集成测试覆盖。


## M2 独立枚举配置销售

新增通用 `<ConfigOptionRenderer />`，按后端公开字段渲染 Element Plus select；组件不解析魔方私有结构。选配变更立即清空报价，版本计数阻止迟到报价覆盖新选择；重新报价按钮用于过期/变价恢复。目录展示默认配置参考价，下单页分别展示首期和周期续费价，账单/实例显示冻结的可读配置摘要。独立枚举以外的联动/滑块/自定义字段本批不支持，详见 [配置销售契约](M2_CONFIG_SALES.md)。本批浏览器在隔离库验证配置切换、下单、账单/实例摘要与 390px 无横向溢出，未连接真实支付或开通。

## 本站域名 VNC 访问要求（2026-11-08）

用户已确认采用“本站页面 + 独立云控制台直连”，隐藏财务域名，允许云域名及临时连接参数在浏览器可见。`/instances/:id/console` 继续使用 Element Plus/noVNC，页面与静态资源在本站，WS 直达云系统。通过本人登录 POST 获取最小参数，仅保存在内存，不挂在页面 URL/历史/sessionStorage 中；不加载财务页面/iframe，不发送本站 Token 或主机密码给云 WS。

按钮提供连接、断开、Ctrl+Alt+Del，状态有连接中/已连接/已断开/失败；断线显式重连。页面 15 分钟/主登录到期主动断开，每 15 秒 POST check 检查资格及 binding；退出/卸载关闭，使用连接代次防止旧事件污染新连接。390px 画布缩放。该页面策略不能强制撤销已返回的上游凭据，真实上游 TTL/撤销需单独证明；详见 [VNC 契约](M2_INSTANCE_VNC.md)。

## 当前运营后台页面契约（2026-11-08）

复用同一 web/ 与 Element Plus 外壳，不实施目录规划中的第二套后台应用。

| 路由 | 页面与权限 | 状态和操作 |
|---|---|---|
| /admin/login | 管理员用户名/密码和既有 login CaptchaWidget；无公开管理员注册 | 登录中禁重交、错误提示、校验成功后只允许跳本批 admin/tasks 路由。客户身份不作为后台身份。 |
| /admin/tasks | 启用管理员可查看的标准表格 | 默认异常关注排除已永久取消结案的任务，failed/all 可查历史；状态/新购续费/任务账单实例 ID 筛选、分页与刷新，筛选和页码保留 URL；加载遮罩、空结果、错误及详情入口。 |
| /admin/tasks/:id | 任务详情、关联账单/实例/客户/上游编号、本地收款凭证、分页人工处理记录 | Element Plus descriptions/table；仅服务端 allowed_actions 生成处理按钮；非 super_admin 提示只读，业务冻结提示无操作。 |

管理员会话以独立 jianyun_admin_token 存 sessionStorage，客户继续 jianyun_token，分别使用 Pinia store 与 401 清理事件，退出后台不清客户登录。路由守卫请求 admin/auth/me 校验当前数据库身份；服务端中间件与裁决事务是权限最终边界，篡改浏览器状态不能获得权限。后台页导航显示管理员身份与异常任务；前台提供后台入口。刷新、直接输入受保护 URL、过期会话返回管理员登录。

人工操作弹窗在打开时冻结所见 execution_token；所有操作必填 10–1000 UTF-8 字节证据，提醒不填密码/密钥。fulfill 要求真实资源编号，续费编号只读；retry/cancel_compensate 额外要求显式未执行确认，后者使用危险按钮并说明永久取消与退站内钱包后果。提交中禁重交、禁关闭；409 关闭旧弹窗并刷新上下文，要求重新核验，不能自动换 token 重试。网络结果不确定时提示先刷新审计核对，资金副作用仍由既有事务和 token 防重。

桌面沿用标准表格；390px 下筛选单列/自适应，表格内部横向滚动，详情长编号/证据换行，弹窗最大宽度为屏幕减 32px，确认文本可换行。时间显式标为 UTC。人工记录只代表成功裁决，Worker 过程继续查原日志，不伪造全量过程时间线。

本批不增加退款自动化、渠道退款或人工退款登记；商品管理/上下架/加价已由下节增量补齐，后续按实例常用运维与本站域名 VNC → 单渠道告警/到期提醒推进。

## 商品管理页面契约（2026-11-08）

同一 Vue 应用后台导航增加“商品管理”，继续使用 Element Plus table/descriptions/form/dialog，客户端保持原应用和独立身份。

| 路由 | 权限、内容与交互 |
|---|---|
| /admin/products | 启用管理员只读；按名称/上游/销售状态筛选与分页，参数保留 URL；展示本地/远端编号、上游名称/驱动/启用状态、可售账期、默认参考价和加价规则。super_admin 可进入导入页。 |
| /admin/products/:id | 绑定、状态、价格、默认选配和分页审计；super_admin 通过弹窗改名称/上下架/加价，页面版本冻结到提交；其他角色仅查看。支持驱动显示快照预览和刷新表单。 |
| /admin/products/import | 仅 super_admin 使用既有上游选择器、远端 PID/名称/类型/加价和账期表单；先读取预览，再确认导入，默认下架，跳转详情后检查并上架。 |

预览仅读取 Schema 和报价；安全字段复用 ConfigOptionRenderer。可改默认配置/账期，变化立即使原确认失效，必须再次预览。刷新可选择“使用上游默认配置”以处理旧字段变化；新商品不需要用户手写原始 Schema。报价区分首期和新购续费参考价，标记预览过期时间 UTC；真实购买仍走实时预检。导入不代表购买或启用销售。

写操作需 10–1000 字节依据并提示不填密钥；加载/提交禁重交，编辑弹窗提交中不可关闭，旧版本 409 后刷新并要求重核。上游失败显示错误且不保存半成品；导入结果不明先核对列表/审计，不能另建新意图盲重交。列表/详情具备加载、空数据、错误、刷新，审计单独分页；390px 下表单自适应、表格容器内滚动、弹窗屏宽减 32px、长编号/依据换行。

本批只维护目录商品，不提供 Provider 凭据编辑、删除商品、实例改价、渠道退款或高级选配；下架和新目录价不改历史账单、实例续费价及既有履约/调查。

## 实例电源面板（2026-11-08）

复用客户 `/instances/:id` 与 Element Plus Card/Tag/Button/Table/MessageBox；仅已交付 active 实例加载独立 runtime 面板，列表不批量请求上游。展示实时运行状态、UTC 查询时间、按后端能力/状态开放的开关机和重启按钮，以及最近 10 条操作及结果。unknown、unsupported 和阻断状态不开放提交。

写操作先明确确认业务中断风险，按钮锁定防重复；确认令牌保持弹窗打开时的原值，过期/冲突由后端拒绝。请求结果不确定时先刷新原任务，不能自动再发。pending/running/investigating 每 15 秒串行查询，离开页面停止；成功明确显示“上游已确认接受命令”，不声称 OS 已完成重启。待核验提示联系管理员，原电源任务未结束前禁用续费提交。表格移动端内部滚动，沿用单一布局。

2026-11-09 状态跟踪收敛：没有本站在途任务但读到 transitioning 时，也每15秒串行查询、最多2分钟；明确 on/off 后停止，未知／网络失败在剩余窗口内继续查，超时提示手动刷新，手动刷新可重新开启窗口。页面离开停止，不改任何 Outbox 终态。重装自动轮询改用 `?view=tasks` 只读本地历史，失效旧提交令牌；初次进入、手动刷新与任务结束后才完整读取镜像／能力与新确认。失败保留原任务记录、显示错误并继续在途轮询，不展示旧能力为可提交。执行结果仍由 Worker 原证据规则裁决。

管理员 `/admin/tasks` 增加 power 筛选，原详情/证据弹窗承载 investigate、原资源 fulfill 和 close_unexecuted；禁止显示通用重试或退款。无账单显示不适用，继续按后端 allowed_actions 展示且写时重新校验。本站 VNC 后续单独交付。完整边界见 [电源契约](M2_INSTANCE_POWER.md)。

## 上游接入页面

`/admin/providers`、`/admin/providers/new`、`/admin/providers/:id` 复用单应用外壳和 Element Plus。列表筛选／分页留 URL，详情查看配置标识、关联数量与分页审计；超级管理员可创建、版本校验改名和只读验证。驱动动态声明表单，凭据不回填，提交后清空；响应丢失保留本页请求键，重试同参数找回原连接。换账号新建连接，页面不提供改账号、启停、删除、迁移资源或代登录。验证只显示脱敏参考价，连接与商品导入／实例查询互链，导入预选连接和验证商品 PID；原快照预览／确认及默认下架保持。权限、异常与移动端验收见 [本批契约](M2_PROVIDER_CONNECTIONS.md)。

## 客户重装最小页面

现有实例详情中的 InstanceReinstallPanel 使用 Element Plus 选择框、备份／清盘勾选、二次确认弹窗和操作记录；仅能力允许时提交。上游生成密码说明固定展示，无假密码输入框；data_disk 为不请求格式化，仍提示备份。未决重装清除已展开凭据，后端拒绝旧密码，重装结果与交付状态分别展示。正常任务显示已受理／执行跟踪／等待凭据，异常才提示管理员。自动执行结束显示 execution_ended 与上游提供的未验证凭据，不当作系统成功或登录验证；单个运行状态不能替代重装成功。桌面／手机使用原布局与表格内部滚动，异常／空能力保留刷新；仅原页面提交的任务明确受理后弹一次“重装请求成功”，入队仍显示等待响应；随后联动顶部运行状态立即刷新，并在任务占用期间每15秒持续查询，即使没有电源任务也不保留陈旧状态。历史受理记录／未知提交不弹成功。实际验证见 [重装契约](M2_INSTANCE_REINSTALL.md)。
